# Contributing

Thank you for your interest in contributing to this project!

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Install dependencies.

```bash
uv sync
```

4. Create a feature branch.

```bash
git checkout -b feature/my-feature
```

5. Make your changes.

6. Run tests (when available).

```bash
uv run pytest
```

7. Commit using clear commit messages.

Example:

```text
feat: add manager agent
fix: resolve Ollama connection issue
docs: improve README
```

8. Push your branch.

```bash
git push origin feature/my-feature
```

9. Open a Pull Request.

---

# Coding Guidelines

- Keep functions small and focused.
- Write readable code.
- Add documentation for new features.
- Follow the existing project structure.
- Test changes before submitting.

---

# Reporting Issues

When reporting bugs, please include:

- Operating System
- Python version
- AutoGen version
- Ollama version
- Steps to reproduce
- Error message

---

# Feature Requests

Feature requests are welcome.

Please describe:

- The problem
- Proposed solution
- Expected behavior
