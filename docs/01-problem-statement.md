# Background

Artificial Intelligence is becoming increasingly capable of performing complex tasks through autonomous AI agents. Many existing solutions rely on cloud-based AI services, which require internet connectivity and paid API access.

Developers who want to learn AI agents locally often face challenges in setting up a complete development environment and understanding how multiple agents can collaborate.

---

# Problem

There is no simple, beginner-friendly project that demonstrates how to:

- Install Microsoft AutoGen
- Connect AutoGen with a local Ollama server
- Build AI agents locally
- Enable multiple AI agents to collaborate
- Develop AI applications without paid cloud APIs

As a result, many developers struggle to understand how to build practical AI agent systems.

---

# Proposed Solution

This project provides a fully local implementation of Microsoft's AutoGen framework integrated with Ollama.

The project demonstrates how AI agents can communicate, collaborate, and complete tasks while running entirely on a local machine.

It also serves as a reusable learning project and a foundation for more advanced AI applications.

---

# Objectives

The project aims to:

- Learn Microsoft AutoGen
- Learn local LLM integration
- Understand agent collaboration
- Build reusable AI components
- Create a portfolio-quality AI project
- Establish a repeatable development workflow

---

# Target Users

This project is intended for:
