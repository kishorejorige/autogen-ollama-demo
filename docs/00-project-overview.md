# Executive Summary

AutoGen + Ollama Demo is a local AI multi-agent project built using Microsoft's AutoGen framework and Ollama.

The goal of this project is to learn how AI agents can communicate, collaborate, and solve tasks while running entirely on a local machine without relying on paid cloud APIs.

---

# Project Goals

- Learn Microsoft AutoGen
- Connect AutoGen with Ollama
- Build local AI agents
- Build multi-agent workflows
- Create reusable AI components
- Learn agent collaboration
- Build a portfolio-quality project
