# Purpose

This roadmap outlines the planned development phases for the AutoGen + Ollama Demo project.

Each phase builds upon the previous one, allowing the project to grow incrementally while remaining stable and testable.

---

# Development Roadmap

## Phase 1 – Project Setup ✅

### Goals

- Initialize project with `uv`
- Configure Python environment
- Create Git repository
- Create documentation structure
- Push project to GitHub

### Deliverables

- Working project structure
- GitHub repository
- Initial documentation

---

## Phase 2 – Local AI Integration ✅

### Goals

- Install Microsoft AutoGen
- Install Ollama integration

- Verify local model communication

### Deliverables

- Working AutoGen environment
- Successful Ollama connection
